📚 Learning Dashboard

A modern, interactive **Learning Dashboard** designed to help students access courses, track their learning progress, and practice knowledge through questions and assessments.

The project provides a clean and responsive interface for managing learning content, viewing courses, and engaging with course-related questions.

---

🚀 Project Overview

The **Learning Dashboard** is a web-based learning platform that brings course content, learning progress, and assessments together in one place.

The goal is to provide students with a simple interface where they can:

* 📖 Explore available courses
* ➕ Add courses to their learning dashboard
* 📊 Track learning progress
* 📝 Practice course-related questions
* 🎯 Attempt V2 assessment questions
* 💻 Access learning content through a responsive interface
* 🖼️ View course content with an interactive UI

---

✨ Features

 📚 Course Management

* Display available courses
* Course cards with relevant information
* Add courses to the learner's dashboard
* View selected/enrolled courses
* Organize learning content

📊 Learning Dashboard

The dashboard provides an overview of the student's learning activities.

It can include:

* Total courses
* Active courses
* Completed courses
* Learning progress
* Course-wise progress
* Assessment activity

📝 V2 Questions

The project includes a **V2 Questions** section for practicing and evaluating knowledge.

Students can:

* View V2 questions
* Read questions related to the course
* Select answers
* Practice assessment questions
* Review their learning through question-based activities

> **Note:** The exact V2 questions can be added to this section based on the question bank used in the project.

 🎨 Responsive UI

The interface is designed to work across:

* 💻 Desktop
* 📱 Mobile
* 📟 Tablet

The design focuses on readability, simple navigation, and a modern learning experience.

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/janani182006/Learning-dashboard.git
```

### 2. Navigate to the project

```bash
cd Learning-dashboard
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
ng serve
```

### 5. Open in browser

```text
http://localhost:4200/
```
